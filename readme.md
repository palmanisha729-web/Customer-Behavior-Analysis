# Data Analytics Project | Python, SQL, Power BI

## Overview

This project showcases an **end-to-end data analytics pipeline**, from raw data to business insights.
It demonstrates hands-on experience with **Python, SQL, and Power BI**, following real-world analytical workflows.

---

## Key Skills Demonstrated

* Data cleaning & exploratory data analysis (EDA)
* SQL-based data analysis across relational databases
* Interactive dashboard development
* Insight-driven reporting and presentation

---

## Dataset

* Structured tabular dataset (CSV)
* Includes categorical, numerical, and date fields
* Cleaned and transformed for analysis and reporting

---

## Tools & Technologies

* **Python:** Pandas, NumPy, Matplotlib, Seaborn
* **SQL:** PostgreSQL / MySQL / SQL Server
* **BI Tool:** Power BI
* **Reporting:** Analytical report + presentation (Gamma)

---

## Workflow

1. Loaded and explored data using Python
2. Performed EDA to identify patterns, trends, and anomalies
3. Cleaned and prepared data for analysis
4. Executed SQL queries using joins, aggregations, subqueries, and window functions
5. Built an interactive Power BI dashboard
6. Summarized insights in a report and stakeholder-ready presentation

---

## Dashboard Highlights

* KPI tracking
* Trend and category analysis
* Interactive filters and slicers
* Business-focused visual design

---

## Results

* Identified key performance drivers and trends
* Highlighted top-performing categories and regions
* Delivered actionable insights for data-driven decision-making

---

## How to Run

1. Install Python dependencies

   ```bash
   pip install pandas numpy matplotlib seaborn
   ```
2. Run Python scripts/notebooks for EDA and cleaning
3. Load cleaned data into SQL database
4. Execute SQL queries
5. Open Power BI file and refresh data
